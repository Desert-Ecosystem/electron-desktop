# Desert Desktop

Официальное приложение [Desert Messenger](https://desert-chat.ru).

Репозиторий содержит обертку над веб-фронтендом Desert (`https://app.desert-chat.ru`), предоставляющую ему доступ к системным API: захват экрана, уведомления и т.д.

## Что это?

Приложение загружает веб-версию Desert и расширяет ее нативными возможностями через строго ограниченный `preload` (`window.api`), предоставляя веб-фронтенду доступ к системным API.

## Мотивация публикации открытого кода

### Доверие

На данный момент проект некоммерческий и у нас нет платных сертификатов. Код опубликован с целью возможности проверки на вредоносный функционал.

Каждый может собрать приложение из исходников и убедиться, что в релизе нет ничего лишнего.

### Расширяемость

В будущем планируется возможность интеграции модулей сообщества.

Открытый код делает такую модификацию прозрачной и доступной для всех.

## Почему Electron?

- JS/TS являются очень доступными языками и одними из самых популярных. Это сделает модификацию Desert более доступной в будущем.
- Использование Chromium позволяет добиться повторяемого на всех платформах отображения интерфейса.
- Изначально использовался Tauri, но поддержка CEF вместо нативного WebView является экспериментальной, что стало основной причиной отказа.

```bash

```

### Build

```bash

$ pnpm build:win

# For macOS

$ pnpm build:linux
```
